# Симуляция кругов

Клиентское приложение с двухмерной физической симуляцией движения и столкновения круговых объектов.

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```
После запуска приложение будет доступно по адресу, указанному Vite в терминале.

## Сборка

```bash
npm run build
```

## Требования к проекту

- игровая область не менее 50% окна браузера;
- возможность добавлять произвольное количество объектов;
- настройка радиуса, направления и скорости для каждого объекта;
- взаимодействие объектов с границами области и между собой;
- визуализация через WebGL2;
- сохранение и восстановление состояния симуляции;
- клиентское приложение;
- отсутствие сторонних UI-библиотек, графических и физических движков.

## Физика

- интервал расчёта физики: 60 раз в секунду;
- столкновения: абсолютно упругие;
- масса круга: radius²;
- редактируемый объект исключается из расчетов.

## Архитектура

```text
src/
  app/
    App.ts                 — главный цикл и координация приложения.
                             хранит массив кругов и связывает физику, рендерер, интерфейс и хранилище.
    Physics.ts             — движение и разрешение столкновений.
    Render.ts              — WebGL2-рендеринг, компиляция шейдеров, управление размером canvas.
    Storage.ts             — сохранение состояния в Local Storage, сериализация и чтение данных. 
    interface/
      AppInterface.ts      — сборка интерфейса и связь UI-компонентов
      CircleEditor.ts      — конфигуратор выбранного круга (радиус/скорость/направление/цвет)
      CircleList.ts        — галерея карточек кругов
      SavesControl.ts      — управление сохранениями
      SimulationStats.ts   — отображение FPS и количества кругов
  data/
    constants.ts           — параметры симуляции и WebGL-шейдеры
    types.ts               — типы данных
  utils/
    domHelpers.ts          — создание общих DOM-элементов
    utils.ts               — математические функции и работа с цветом
```
