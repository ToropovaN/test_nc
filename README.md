# Симуляция кругов

Клиентское приложение с двухмерной физической симуляцией движения и столкновения круговых объектов.

## Демо

> **⚙️ <u>Version 2</u> - Engineer Edition** <br>
> <u>Массовая симуляция однотипных объектов: оптимизация рендеринга и физики</u>  <br>
> https://toropovan.github.io/test_nc/engineer-edition/ <br>

> 🎨 Version 1 - Frontend Edition  <br>
> Индивидуальная настройка объектов <br>
> https://toropovan.github.io/test_nc/frontend-edition/ <br>

## Установка

```bash
npm install
```

## Запуск

```bash
git switch v1 #для запуска первой версии

npm run dev
```

После запуска приложение будет доступно по адресу, указанному Vite в терминале.

## Сборка

```bash
npm run build
```

## Требования к проекту

- игровая область не менее 50% окна браузера;
- возможность добавлять произвольное количество объектов;
- настройка радиуса, направления и скорости для каждого объекта;
- взаимодействие объектов с границами области и между собой;
- визуализация через WebGL2;
- сохранение и восстановление состояния симуляции;
- клиентское приложение;
- отсутствие сторонних UI-библиотек, графических и физических движков.

## Физика

- адаптивный временной шаг (снижение риска туннелирования);
- настраиваемый коэффициент упругости;
- единые физические параметры объектов;
- устранение пересечений позиционной коррекцией;
- изменение скорости через импульс;
- пространственная сетка для поиска потенциальных столкновений.

## Архитектура

```text
src/
  main.ts                   — точка входа
  app/
    App.ts                  — главный цикл и координация модулей
    Physics.ts              — движение и разрешение столкновений
    Render.ts               — WebGL2-рендеринг и управление canvas
    Storage.ts              — сохранение и валидация данных Local Storage
    interface/
      AppInterface.ts       — композиция UI и обработчиков действий
      CircleEditor.ts       — настройка параметров симуляции
      SavesControl.ts       — управление сохранениями
      SimulationStats.ts    — отображение статистики
  data/
    constants.ts            — константы и WebGL-шейдеры
    types.ts                — общие типы данных
  utils/
    domHelpers.ts           — создание DOM-элементов
    utils.ts                — математика и преобразование цветов
  assets/                   — шрифт и SVG-иконки
  style.css                 — стили приложения
```
